# Practice: Intermediate Pull Request with Code Review

## Task Brief
Create a feature branch for SQL query functions, submit a pull request, respond to code review feedback, and merge to main.

## Scenario
Your team needs SQL query functions for the Iris pipeline. Create a PR, handle review comments, and merge cleanly.

## Deliverables
- Feature branch with SQL query functions
- Merged pull request with review history

## Success Criteria
- PR includes at least 2 SQL queries
- Responds to at least one review comment
